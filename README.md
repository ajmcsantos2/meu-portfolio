# Meu Portfólio Pessoal

Este é o meu portfólio pessoal desenvolvido para expor meus projetos, certificados e um pouco sobre a minha trajetória acadêmica e profissional. O site conta com um layout moderno e um recurso de alternância de tema (Dark/Light Mode).

## Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais do desenvolvimento Web:

*   **HTML5:** Estruturação semântica das páginas (`index.html`, `projetos.html`, `certificados.html`).
*   **CSS3:** Estilização personalizada, layout responsivo e gerenciamento de cores do tema.
*   **JavaScript:** Lógica de interatividade, incluindo o botão de alternar tema (Light/Dark mode).

## Estrutura do Projeto

O repositório está organizado da seguinte forma:

*   `index.html` - Página principal (Home / Sobre Mim).
*   `projetos.html` - Galeria com os meus principais projetos desenvolvidos.
*   `certificados.html` - Exibição das minhas qualificações e cursos extras concluídos.
*   `style.css` - Arquivo responsável por toda a identidade visual do site.
*   `script.js` - Scripts de interatividade e manipulação do DOM.
